# 人工智能流水线 · 场景调整版

给队友调场景位置和动作用的。

---

## 怎么打开

1. 装 **Node.js**（如果没装）：https://nodejs.org/ 选 **LTS** 版本，一路下一步
2. **双击 `start.bat`**
3. 浏览器会自动打开；没打开就手动访问 `http://127.0.0.1:8123`

关掉黑色窗口就退出。

---

## 怎么调

右上角有「物体属性」面板。

### 选房间

```
[① 接单] [② 思考]
[③ 执行] [④ 交付]
```

点哪个就调哪个。

### 位置

| 滑块 | 作用 |
|---|---|
| 横向 X | 人在房间里左右挪（-1.2 ~ 1.2 米） |
| 前后 Z | 人前后挪（-1.5 ~ 0.5 米，越负越靠墙） |

### 动作

下拉框选动作片段，改完立刻生效。可选的：

```
Idle_Loop              Interact
Interact2              Idle_FoldArms_Loop
Idle_Talking_Loop      Sitting_Idle_Loop
Chest_Open             PickUp_Table
OverhandThrow          Push_Loop
Fixing_Kneeling
```

> 静态工位不要选 `Walk_*` 开头的，人会原地走路。

### 相机

| 滑块 | 作用 |
|---|---|
| 距离 | 2.2 ~ 8 米 |
| 高度 | 1.2 ~ 4 米 |
| 偏右 | 相机左右偏移 |
| 视角 | 24 ~ 60 度 |

**直接用鼠标更快：**

- **拖动画面空白处** → 绕房间转视角
- **滚轮** → 拉近拉远
- **按住小人拖动** → 直接把他拖到想要的位置

### 回放进度

```
[播放/暂停] ──●──────── 3/11
```

- 拖动进度条可以跳到任意一条事件，画面会同步
- 「速度」控制每条事件停多久（300~3000 毫秒）

## 常见问题

**Q：打开是黑屏 / 没有小人**
等 10-20 秒。模型一共 200 MB，第一次加载慢。

**Q：界面动了但画面没反应**
按 `Ctrl + Shift + R` 强制刷新。

**Q：端口被占用**
改 `start.bat` 最后一行的 `8123` 为别的数字（比如 `8124`）。

**Q：想关掉右侧面板录屏**
访问 `http://127.0.0.1:8123/?inspector=0`
