# AI 打工人 · 一条可视化 AI 工作流的流水线

把 **DeepSeek Harness（DSH）** 的真实运行过程，变成一条工厂流水线：
一件货从传送带进来，经过思考、执行，最后送到出口。

> 不是预渲染动画。拔掉 DSH，货就停住。

---

## 一句话

智能体干活时你只看到滚动的日志。这个项目把那些日志变成**一条会动的产线**：
货走到哪一站，哪一站就亮起来干活。

---

## 流水线

```
① 接单            ② 思考              ③ 执行            ④ 交付
传送带送进来  →  箱子 + 大屏刷信息  →  一排机械臂干活  →  送到出口
```

| 站位 | 对应真实事件 | 画面上发生什么 |
|---|---|---|
| ① 接单 | `turn/start` | 传送带滚动，货箱从入口送进来 |
| ② 思考 | `todo/write` | 货进处理箱，箱顶大屏刷新数据条和波形 |
| ③ 执行 | `tool/call` | 三只机械臂在货箱上方作业，火花闪烁 |
| ④ 交付 | `tool/result` | 货滑进出口，红光闪一下 |

**同一件货**从左走到右。走到哪一站，哪一站的地面圆环亮起、灯变色、机器开始动。

---

## 它怎么跑

```
DSH 会话日志（~/.dsh/sessions/**/session.v4.jsonl.zstd）
        │ 只读，逐 zstd 帧解码
        ▼
bridge.mjs ──SSE──▶ http://127.0.0.1:8791/events
        │
        ▼
3D 页面 ← 事件驱动货的位置和每一站的状态
```

**不改 DSH、不装插件、不 hook**，只读它自己的会话文件。

事件的真实时长被保留：一个工具跑了 2.8 秒，机械臂就干 2.8 秒。

---

## 运行

```bat
双击 start.bat
```

- 回放模式（默认）：播一段真实会话，可拖进度条
- 实时模式：`http://127.0.0.1:8123/?source=live`

需要 **Node.js 22.15+**。

---

## 技术栈

| 部分 | 用的什么 |
|---|---|
| 渲染 | three.js 0.167 + @react-three/fiber |
| 构建 | Vite 5 + React 18 + TypeScript |
| 状态 | zustand |
| 场景资产 | Aholo Lux3D 生成的 GLB（人物/家具/道具） |
| 实时接入 | 自写 SSE 桥，解 `session.v4.jsonl.zstd` |

### 渲染细节

- 阴影贴图 2048²，PCF 软阴影
- `RoomEnvironment` + PMREM 程序化环境光（离线可用）
- ACES Filmic 色调映射，曝光 1.35
- 大屏内容用 canvas 逐帧绘制（数据条 + 百分比 + 波形 + 扫描线）
- 传送带 34 根滚轮独立旋转，转速随状态变化
- 三只机械臂各自相位错开，肩/肘/夹爪独立运动

---

## 已知限制

1. 机械臂是程序化关节动画，不是物理仿真
2. 大屏数据是随机生成的，只表示"在思考"，不是真实 token 流
3. 货只有一件，多任务时是排队而不是多货并行
4. 场景偏暗，投影仪上可能更暗，演示前建议调显示器亮度
